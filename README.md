# Дипломный проект — Kinopoisk QA

## Описание проекта

Дипломный проект посвящён функциональному
и API-тестированию веб-сервиса Кинопоиск.

Цель — продемонстрировать полный цикл
тестирования программного обеспечения:
подготовку тестовой документации,
автоматизацию проверок и анализ результатов.

## Технологии

- Python
- pytest
- Playwright
- Requests
- Allure Report
- Postman
- TestIT

## Автоматизированные тесты

### API — 5 тестов

1. Получение списка фильмов.
2. Поиск фильма по названию.
3. Получение информации о фильме по ID.
4. Проверка некорректного числового ID.
5. Проверка буквенного ID.

### UI — 5 тестов

1. Открытие главной страницы.
2. Поиск фильма по полному названию.
3. Открытие карточки фильма из поиска.
4. Проверка информации о фильме.
5. Фильтрация фильмов по году выпуска.

## Установка

Создать виртуальное окружение:

python -m venv .venv

Активировать его в Windows PowerShell:

.venv\Scripts\Activate.ps1

Установить зависимости:

python -m pip install -r requirements.txt

Установить браузер Chromium:

python -m playwright install chromium

## Настройка API

Создать файл .env в корне проекта:

API_TOKEN=ваш_api_ключ
BASE_URL=https://api.kinopoisk.dev/v1.4

Файл .env не должен публиковаться на GitHub.

## Запуск тестов

Запуск всех тестов:

python -m pytest tests/ -v

Запуск только API-тестов:

python -m pytest tests/test_api_movies.py -v

Запуск только UI-тестов:

python -m pytest tests/test_ui_movies.py -v

## Отчёт Allure

Сформировать результаты:

python -m pytest tests/ -v --alluredir=allure-results --clean-alluredir

Открыть отчёт при установленном Allure CLI:

allure serve allure-results
